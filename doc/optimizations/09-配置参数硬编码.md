# 配置参数全部硬编码，无法运行时调整

## 严重程度

**工程化改进 —— 影响可维护性和调优**

## 位置

分散在多个文件中

## 硬编码参数清单

| 参数 | 当前值 | 位置 | 含义 |
|:---|:---|:---|:---|
| `ALIGNMENT` | 8 | `Common.h:9` | 最小对齐字节 |
| `MAX_BYTES` | 256KB | `Common.h:10` | 内存池最大管理大小 |
| `SPAN_PAGES` | 8 | `CentralCache.cpp:49` | 每次向 PageCache 申请的页数 |
| `BATCH_SIZE` | 1（隐式） | `CentralCache.cpp` | 向 ThreadCache 传输块数 |
| `MAX_DELAY_COUNT` | 48 | `CentralCache.h:56` | 延迟归还触发计数 |
| `DELAY_INTERVAL` | 1000ms | `CentralCache.cpp:44` | 延迟归还时间间隔 |
| `归还阈值` | 256 | `ThreadCache.cpp:67` | freeListSize_ 超此值触发返还 |
| `保留比例` | 1/4 | `ThreadCache.cpp:111` | returnToCentralCache 保留比例 |
| `spanTrackers_` 上限 | 1024 | `CentralCache.h:52` | Span 追踪器数组大小 |
| `MAX_CACHED_PAGES` | 无 | `PageCache.cpp` | PageCache 缓存页上限 |

## 修复方案

提供一个统一的配置结构体：

```cpp
// include/Config.h
namespace Kama_memoryPool {

struct PoolConfig {
    size_t alignment        = 8;
    size_t maxBytes         = 256 * 1024;
    size_t spanPages        = 8;
    size_t batchSize        = 8;
    size_t maxDelayCount    = 48;
    size_t delayIntervalMs  = 1000;
    size_t returnThreshold  = 256;
    float  keepRatio        = 0.25f;
    size_t maxSpanTrackers  = 1024;
    size_t maxCachedPages   = 32768;   // 128MB
    bool   releaseToOS      = true;

    static PoolConfig& get() {
        static PoolConfig cfg;
        return cfg;
    }
};

} // namespace
```

使用时：
```cpp
// 替换硬编码
size_t threshold = PoolConfig::get().returnThreshold;

// 用户可在启动时修改
PoolConfig::get().returnThreshold = 512;
```

也可以通过环境变量初始化：
```cpp
void PoolConfig::loadFromEnv() {
    if (const char* v = getenv("MP_MAX_BYTES"))
        maxBytes = std::stoul(v);
    // ...
}
```
